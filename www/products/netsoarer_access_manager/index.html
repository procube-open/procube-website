NetSoarer® Access Manager

SAMLシングルサインオン環境 認証サーバ（SAML IdP） 情報システムのユーザーユーザのセッションを一元管理し、シングルサインオン機能を提供IDの管理を一元化

ABOUT NetSoarer® Access Managerとは

NetSoarer® Access Manager はユーザのセッションを一元管理し、シングルサインオン機能を提供します。
すなわち、ユーザはNetSoarer® Access Manager に、一度ログインすると、
連携している他のWebアプリケーションにはパスワード入力なしでアクセスできます。

また、FIDO、SSL相互認証、ワンタイムパスワード、Windows統合認証など、
さまざまな認証方式に対応し、認証機能・アカウンティング機能を集約します。
このことにより、アプリケーションごとに認証機能・アカウンティング機能を実装する必要がなく、
統一されたレベルでセキュリティを確保できます。この機能は、各Webアプリケーションが認証部分を
NetSoarer® Access ManagerのSAMLサービスに委譲していることにより実現されます。

FEATURES NetSoarer® Access Managerの特長

  • Webブラウザで
    簡単に設定・管理

    WebUIで設定が可能です。
    SAML SPの設定（Metadataの登録、削除）やSAML属性の編集などをオンラインで実行できます。

  • 豊富な認証方式に対応

    ID・パスワード認証はもちろん、Windows統合認証、SSLクライアント証明書、FIDO、ワンタイムパスワード（Google AuthenticatorやMicorsoft Authenticatorを使用したTOTP）など、多様な認証方式に対応しています。

  • SAML準拠で
    幅広いサービスと連携

    標準規格SAMLに準拠しており、学術認証フェデレーションやGoogle Workspaceなどの外部サービスとスムーズに連携。柔軟な認証連携を実現します。

  • シングルサインオン（SSO）で利便性向上

    NetSoarer® Web Gateと連携すれば、社内外のさまざまなWebアプリケーションへのシングルサインオンが可能になり、ユーザーの利便性と業務効率が向上します。

  • 安全な認証ログ管理と
    外部出力

    認証やログを自動的に記録。Syslog形式で外部に出力もでき、セキュリティ監査やトラブルシューティングに役立ちます。

  • 柔軟なユーザ情報の
    連携と制御

    LDAPやRDBMS、Active Directoryなどと連携し、ユーザ属性や組織情報SAMLアサーションに設定。アプリケーションごとの認証・認可制御を細かく行えます。

FAQ よくある質問

NetSoarer® Access Manager で、既存の社内システムやクラウドサービスと連携できますか？

はい、SAML対応のクラウドサービス（例：Google Workspace、学認など）や社内のWebアプリケーションとの連携が可能です。SAML非対応のWebアプリケーションは、NetSoarer Web Gateを導入することでSSO環境を実現できます。

サービスごとに送出する属性を設定できますか？

はい、属性フィルタリング機能で、サービスごとに送出する属性を設定できます。
また、値を別の値に置き換えたり（マッピング）、編集したり（スクリプトの実装）できます。

多要素認証には対応していますか？

はい、ID・パスワードのほかに、FIDO認証、ワンタイムパスワード、SSLクライアント認証、Windows統合認証など、複数の認証方式に対応しており、セキュリティ要件に応じた柔軟な構成が可能です。

認証ログや操作履歴の記録・管理は可能ですか？

はい、認証ログをログファイルに記録します。また、Syslog形式で外部出力も可能です。NetSoarer LogRecorderと組み合わせることで、インシデント調査をサポートでき、セキュリティ対策に役立ちます。

不正ログインを試みる攻撃について対策できますか？

はい、一定時間内に設定回数を超えたログインの失敗が観測された場合、一定時間当該 ID または アクセス元IP、パスワードをロックできます。
これによって、ブルートフォース攻撃やリバースリバース攻撃に対応できます。
