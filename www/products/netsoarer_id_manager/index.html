ID統合管理ソリューション 情報システムのユーザーIDの管理を一元化

ABOUT NetSoarer® ID Managerとは

エンタープライズにおける情報システムのユーザIDの管理を一元化します。
ユーザの属性や組織情報をデータベースに保持し、それらに対する変更情報を受け付けて、末端のシステムに配信します。
例えば、人事異動情報や部門からの申請情報を受け付け、
各業務システム、NetSoarer® Access Manager、Active Directoryなどへ配信します。

FAQ よくある質問

他のID管理システムとの違いは何ですか？

NetSoarer® ID ManagerはWebブラウザによるGUI管理、プロビジョニングの自動化、更新履歴の管理などのID管理に特化した機能を統合しております。データスキーマの拡張性や柔軟なプロビジョニング連携から使いやすさと運用のしやすさが特徴です。

社内の既存システムとの連携は可能ですか？

はい、CSV形式によるデータのインポート／エクスポートに対応しているほか、SSHを用いた外部システムへの自動連携（プロビジョニング）も可能です。柔軟な連携機能でスムーズな導入ができます。

セキュリティ対策はどのようにされていますか？

TLS（SSL）による暗号化通信に対応し、証明書による安全な認証が可能です。また、管理権限の細分化や更新履歴の保持により、不正アクセスや変更の追跡にも対応しています。
