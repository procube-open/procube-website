NetSoarer® Web Gate

SAML シングルサインオン対応ロードバランサ プロキシ型のシングルサインオンを実現

ABOUT NetSoarer® Web Gateとは

SAML非対応のアプケーションをSAML連携させる場合、プロキシ型のシングルサインオンを実現する必要があります。
NetSoarer® Web Gateでは、NetSoarer® Access ManagerなどのSAML IdPと連携して、プロキシ型のシングルサインオンを実現します。

クライアントからのWebサーバに対するリクエストを、複数のバックエンドに分散して要求します。
バックエンドが発行するセッションIDを参照して、一つのセッションに関する複数のリクエストを1個の同じWebサーバに配信します。

FEATURES NetSoarer® Web Gateの特長

  • Webブラウザで簡単設定

    WebUIで設定が可能です。
    SAML IdPとの連携設定（Metadataの登録、削除）やSAML属性マッピングの編集などをオンラインで実行できます。

  • SAML連携による
    認証プロキシ

    SAML SPとして動作し、バックエンドのWebアプリケーションをSAMLで認証。NetSoarer® Access Managerと組み合わせることで、シームレスなシングルサインオン（SSO）を実現します。

  • 自動ログインによる
    ユーザなりかわり機能

    フォーム認証やBasic認証に対応したアプリケーションに対して、ユーザになりかわって自動ログイン。既存システムの改修を最小限に抑えつつSSOが可能です。

  • ユーザ属性の
    HTTPヘッダ連携

    SAMLアサーションの属性情報（ユーザ名、所属など）をHTTPヘッダに付加してWebアプリに転送。アプリケーション側で容易にユーザ情報を取得できます。

  • SSLアクセラレータ機能

    SSLの暗号化・復号化をWeb Gate側で処理し、Webサーバへの負荷を軽減。セキュリティとパフォーマンスの両立を実現します。

  • Webロードバランサ機能

    複数のWebサーバにリクエストを分散させるロードバランサとして動作。高いパフォーマンスと安定したサービス提供をサポートします。

  • 高可用性構成に対応
    （HA構成）

    HA構成による冗長化が可能。障害発生時もサービスを継続できる、信頼性の高い運用を実現します。

FAQ よくある質問

NetSoarer® Web Gateを導入すると、既存のWebアプリケーションを改修せずにシングルサインオンが可能になりますか？

はい、フォーム認証やBasic認証に対応しているアプリケーションであれば、Web Gateがユーザになりかわって自動ログインを行うため、改修なしでSSOが実現可能です。

他のID認証プロバイダと連携できますか？

はい、他のSAML IdP（Microsoft Entra ID（旧：AzureAD ）、Google Workspace、Oktaなど）と連携できます。NetSoarer ID ManagerおよびNetSoarer AccessManagerと組み合わせることで高度な認証連携が可能になります。

Web Gateはクラスタ構成（HA構成）に対応していますか？

はい、Web Gateは高可用性（HA）構成に対応しており、冗長化による障害時の自動切り替えも可能です。安定した運用環境を提供できます。

サーバ証明書の自動管理ができますか？

はい、ACME を使用した証明書の自動発行が可能です。
Let’s Encryptでサーバ証明書を発行し、ダウンロードします（有効期限は3ヶ月）。夜間バッチで有効期限まで1ヶ月を切ると自動更新します。
